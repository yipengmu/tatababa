# 视觉参考与取舍

本项目只参考开源项目的设计原则和信息组织方式，不复制现成页面、品牌资产或组件代码。

## 参考来源

### Marginalia

- 地址：<https://github.com/uxderrick/marginalia>
- 借鉴：以章节组织个人故事、编辑感排版、集中设计变量、尊重 `prefers-reduced-motion`。
- 不采用：油画世界观、大面积场景背景和强滚动叙事。这些表达会压过本站的真实内容和作品。

### MotionFolio

- 地址：<https://github.com/zickrian/motionfolio>
- 借鉴：内容与布局分离、统一的动效节奏、作品卡片作为持续扩展单元。
- 不采用：AI 终端、重型滚动动画和技术栈展示。本站的主角是人，不是开发工具。

### Vercel Portfolio Templates

- 地址：<https://vercel.com/templates/portfolio>
- 借鉴：单页作品集的清晰阅读路径、快速加载、分享信息与 Vercel 部署习惯。
- 不采用：通用履历模板结构。本站不是求职简历，而是工作、育儿与生活的长期个人现场。

## 本站最终视觉原则

1. 人物认知先于链接数量；
2. 三个专题并列，但始终属于同一个人；
3. 使用真实二维码、真实作品截图和真实内容，不使用泛化 AI 机器人图片；
4. 科技感通过网格、编号、运动轨迹和微交互表达，不依赖霓虹渐变；
5. 动效提供方向感，不延迟阅读；
6. 所有动画在“减少动态效果”模式下自动收敛。
